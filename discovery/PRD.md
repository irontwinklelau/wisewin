## 1. Executive Summary

「商业内功每日一练」是一个**服务于个人的博弈能力训练系统**。它不推送内容，而是扮演教练+陪练+复盘师三位一体的角色，帮助用户每天花 15-20 分钟，系统性地训练商业博弈所需的心理能力。第一期聚焦"不被 PUA"——从受害者叙事觉察→框架化表达→自我估值校准，三步重建底层操作系统。产品形态为 Web 应用，要求交互质感好、界面干净（参考 Sigma App 风格）。

---

## 2. Background & Context

### 触发原点
用户观看电视剧《她的盛焰》后，对主角饶雨瓷的博弈能力产生强烈共鸣——她能精准预判他人痛点、用利益交换达成目标、说"聪明话"。用户意识到自己缺乏这种能力，但面临"复利思维反噬"困境：知道需要每天积累，却找不到可执行的每日动作。

### 核心洞察
- 用户不是缺内容/知识，是缺一个**能带着他每天练的系统**
- 现有的 AI 聊天框（Gemini 等）无法提供结构化训练体验
- 菲森面试审计报告（2026-07-13）暴露了三个具体短板：受害者叙事、框架化表达缺失、自我估值能力为零
- 这四个能力有上下依赖关系：**不被 PUA → 读人痛点 → 利益交换 → 聪明话**

### 为什么现在做
用户明确表示"只要不出 bug，我天天用"。当前没有替代品——Sigma App 风格喜欢但不是训练工具，AI 聊天框不够结构化。

## 3. Objectives & Success Metrics

### Goals
1. **首要目标**：用户连续使用 30 天不中断
2. 完成"不被 PUA"三个模块的全部训练（叙事觉察→框架化表达→自我估值校准）
3. 升级到 LV.1（通过受害者叙事觉察测验）

### Non-Goals（明确不做）
1. ❌ 不做社区/社交功能（现阶段仅服务用户一人）
2. ❌ 不做移动端 App（Web 优先，PWA 可后续考虑）
3. ❌ 不做内容平台——不抓取外部文章、不推送资讯
4. ❌ 不做"真实战场回报"功能（留到 LV.3 以后）
5. ❌ 不一次性展示所有课程大纲——按段位逐步解锁

### Success Metrics

| Metric | Current | Target | Measurement |
|--------|---------|--------|-------------|
| 连续使用天数 | 0 | ≥ 30 天 | 打卡记录 |
| 每日训练完成率 | — | ≥ 80%（30天中完成24天） | 训练完成标记 |
| 受害者叙事觉察测验通过 | 未测试 | LV.1 升级 | 测验得分 ≥ 80% |
| 知识武器库条目数 | 0 | ≥ 15 个框架（30天后） | 武器库计数 |
| Bug 导致中断次数 | — | 0 | 用户反馈 |

| P0-6 | 作为学习者，产品不出 bug，不能因为技术问题打断我的训练节奏 | ①每日训练流程无阻断性 bug ②打卡数据不会丢失 ③页面加载 < 3 秒 |

## 6. Solution Overview

### 产品形态
Web 应用，前端交互质感要求高（参考 Sigma App 的干净风格），后端负责训练内容生成和用户数据持久化。

### 核心交互流

```
打开浏览器 → 看到今天的状态（段位 + 连续天数 + 武器库数量）
  → 进入「今日训练」
    → Step 1: 框架讲解（概念 + 为什么重要 + 1个案例）
    → Step 2: 案例拆解（用你的真实案例深度拆解）
    → Step 3: 当日练习（选择题/填空/重写练习）
    → Step 4: 打卡 + 更新武器库
  → 回到首页，看到段位进度条往前动了
```

### 第一课内容锚点（"受害者叙事觉察"模块第1天）

基于菲森面试审计报告，第一课设计为：
- **框架**：受害者叙事 vs 策略选择者叙事
- **案例**：菲森面试中"只能接受吧…并不是我主动要离开的"这句话
- **练习**：用"策略选择者"视角重写短任期经历
- **打卡**：完成即标记

### 技术选型建议

| 层级 | 方案 | 理由 |
|------|------|------|
| 前端 | React + Tailwind CSS | 用户要求交互质感好，参考 Sigma App |
| 后端 | Python + FastAPI | 与现有原型技术栈一致 |
| 数据 | SQLite | 单用户场景，不需要 MySQL/Postgres |
| AI | Claude API | 训练内容生成 + 练习评估 |
| 部署 | 本地运行（localhost） | 现阶段不需要服务器 |

### 设计原则
1. **渐进式解锁**：LV.0 只能看到第一个模块的第一课，后续内容全部隐藏
2. **教练式口吻**：不是"请学习以下内容"，而是"今天我们来拆解一个你身上的真实案例"
3. **最小认知负荷**：每屏只做一件事，不堆砌信息
4. **仪式感**：打卡瞬间有明显的视觉反馈，升级有庆祝动画
5. **Sigma 风格**：大量留白、克制配色、字体干净、无冗余 UI 元素

### 内容策略
- 训练内容由 Claude API 生成，基于用户真实案例库
- 初始案例库：菲森面试审计报告（HIAE v2.0）
- 后续案例可由用户手动添加或在真实战场回报功能中积累
- 所有框架的定义用**用户自己的语言**注解，不是教科书定义
